# GNOME Wallpaper v0.1.0

发布日期：2026-10-23。完整预编译包面向 **Debian 13 / GNOME 48 / Wayland / x86_64**。

## 完整安装包

后端、必要私有库、GNOME 插件和管理界面现在随一个 ZIP 分发。安装后直接在界面选择自备 assets 和壁纸，不再单独部署 runtime 或配置后端路径。
首页提供首次使用导入引导，空图库不再误报壁纸丢失。资源复制导入有校验、取消、写锁和事务恢复；升级保留资源与用户静态图。

新增完整性与平台检查、原子安装/回滚、构建身份和依赖对应源码校验。源码、构建、发行包、已安装程序及用户数据分离。
保留静态优先、默认 15 FPS、显式动态、独立 4K→1080p 静态截图，以及 Forge、空工作区合成、工作区焦点和多语言文字修复。

## 安装

普通用户下载 `gnome-wallpaper-v0.1.0-linux-x86_64.shell-extension.zip`、`install.py`、`SHA256SUMS`，放在同一目录：

```bash
sha256sum --check --ignore-missing SHA256SUMS
python3 install.py ./gnome-wallpaper-v0.1.0-linux-x86_64.shell-extension.zip
```

安装器不会启用扩展或重启桌面。当前 Shell 未发现扩展或缓存旧代码时，请在方便时重新登录；随后启用扩展并打开设置，导入自己的资源。
通过源码构建安装、系统依赖、启用与迁移步骤见 [README](https://github.com/zcmmy/gnome-wallpaper/blob/v0.1.0/README.md)。

## 附件与来源

- 完整程序 ZIP、统一安装器和 Markdown 安装/验证说明。
- `backend-manifest.json`：构建身份、运行库闭包、宿主 ABI、精确来源与哈希。
- `renderer-corresponding-source.tar.gz`：本版本项目对应源码和构建材料。
- `dependency-corresponding-sources.tar.gz`：所用依赖的精确对应源包；`fetch-sources.py` 为获取工具。
- `SHA256SUMS`：全部发行附件校验值。

两份源码归档供重建和许可审计，不是普通运行的必需下载项。完整包不含任何用户壁纸、公共 assets、静态截图或个人配置。
采用 GPL-3.0-only，保留 portghost、Almamu、GNOME 扩展上游及第三方归属。
