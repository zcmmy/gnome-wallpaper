# GNOME Wallpaper v0.0.1

发布日期：2026-10-19。稳定分支：`main`；开发分支：`dev`；附注标签：`v0.0.1`。
这是自 `v0` 以来的累计发布，包含此前在 dev 上开发的截图功能和两组兼容性修复。

## 修复

### Forge 导致动态壁纸层级冲突

此前渲染窗口的 actor 虽位于背景组，但在 Mutter 中仍为普通窗口。
Forge 会把它加入平铺树；开启“浮动窗口始终置顶”时又会调用 make_above，造成层级冲突。
现在创建时立即将所属窗口声明为 DESKTOP，并在 Forge 先处理创建事件时按客户端归属排除它。
停用插件时清理兼容包装，不修改 Forge 的全局平铺或浮动设置。

隔离验证覆盖 Forge 先启用、后启用、反复开关、动态重启以及热更新，
并与 Blur my Shell、Dash to Dock、Rounded Windows 同时运行。
用户已在真实桌面确认开启动态模式后应用窗口显示正常。
原因、实现与测试入口见 [Forge 兼容说明](../FORGE-COMPATIBILITY.md)。

### 场景和 Puppet 渲染

- 修复旧音频条、边框和环形频谱的 GLSL 兼容问题。
- 修复 Puppet 骨骼元数据解析，以及 Y 反射后网格三角形绕序。
- 修复部分同时使用骨骼动画与多层位移特效的壁纸出现的局部抽动和变形：先在源图空间处理特效，再在最后绘制变形网格，避免遮罩错位。
- 补充分组和图层脚本绑定、跨层文字更新；缺失的用户图片采用透明占位。
- 使用包含上述技术特征的自备素材验证；项目不提供具体壁纸信息或素材。

详见 [渲染兼容验证说明](../RENDERING-COMPATIBILITY.md)。

## 新增：动态播放期间替换静态图

管理界面提供“高质量截图并替换静态图”选项。
动态播放保持运行，另启一次性任务以 4K 渲染场景，再缩小至 1080p，更新静态图、预览和 GNOME 原生壁纸。
视频按原生帧采样。截图时刻可能与桌面不同；支持取消、重复请求保护和用户图片并发修改保护。
缺少静态图时的自动生成继续使用同一高质量流程，日常 FPS 与动态开关不变。

## 升级与部署

```bash
git fetch origin --tags
git switch --detach v0.0.1
make renderer
make extension
make check
make package DEST=/一个尚不存在的新运行目录
```

构建依赖和资源准备见 [安装说明](../INSTALL.md)。升级包含 C++ 和 GNOME 两层，
不能只更新插件就获得本次渲染修复。运行包不含用户 Wallpaper Engine assets 或 Workshop 素材，
应按安装说明自行准备资源。保留现有运行目录和静态图，先验证新运行包再替换。

安装 GNOME 插件使用原子安装器，避免原地覆盖已映射的 gschemas.compiled。
复制文件不会刷新当前会话缓存；常规更新可在下次登录生效，开发会话更新见对应修复文档。
本次发布操作不重启 GNOME、不更改当前桌面外观、不添加开机启动项。

## 验证记录与边界

- 发布前执行 `make check`：C++ 渲染器、GNOME 管理/截图/生命周期、Forge 归属过滤、打包及目录维护检查。
- 开发阶段通过 Puppet 零/一/两层特效的合成像素测试、场景脚本测试和高质量截图集成验证。
- Forge 隔离测试与热更新测试已通过，并补充用户真实桌面验收。
- 本地验证平台为 Debian 13、GNOME 48 / Wayland、x86_64；未验证全部 metadata 声明版本。
- 不保证所有 Workshop 特效兼容；scene/video 运行包不提供完整 Web 壁纸支持。
- 部分壁纸自身包含无效图层引用等脚本问题，渲染器不会自动改写作者引用，详见渲染验证说明。
- Forge 适配使用 version 89 的内部接口，未来扩展更新后需重新验证。
