# GNOME Wallpaper v0.0.2

发布日期：2026-10-19。稳定分支：`main`；开发分支：`dev`；附注标签：`v0.0.2`。

## 修复：空工作区遮挡顶栏与 Dock

动态壁纸在没有普通应用窗口的工作区可能绕过 Shell 的完整合成，遮蔽顶栏和 Dock。
这与 v0.0.1 已修复的 Forge 平铺与置顶问题属于不同路径。
现在在渲染窗口首帧映射前持有 Mutter 合成保护，避免直接扫描输出绕过 Shell 界面。
停止、静态模式、异常退出和停用扩展时释放引用；重复启停与会话更新不会累计引用，
也不会释放其他扩展持有的引用。

不修改顶栏或 Dock 的样式、尺寸、布局，不改变日常 FPS、分辨率、效果或显式动态开关。
静态模式不因此增加渲染进程或定时器。真正全屏应用仍遵循 GNOME 的全屏界面行为。
动态期间该接口也会抑制其他窗口直接扫描输出，可能增加合成成本，不宣称 GPU 开销不变。

[原因与验证边界](https://github.com/zcmmy/gnome-wallpaper/blob/v0.0.2/docs/EMPTY-WORKSPACE-COMPOSITING.md)。

## 插件包与项目整理

- 发布 GNOME 插件 ZIP、原子安装器、Markdown 安装说明和 SHA-256 校验文件。
- ZIP 使用固定条目时间与权限、排序文件列表，在相同 GLib/Python 工具链下可重复构建。
- 更新插件名称与项目链接；保留 UUID，Shell 整数版本号为 2，项目版本为 v0.0.2，内部代码修订号为 14。
- 新安装不再预选开发阶段素材，运行包初始化也清空选择；已有用户选择不受插件升级影响。
- 增加标签构建发布流程，生成物统一位于忽略的 `build/releases/<版本>/`；源码与运行包保持分离。
- 不包含或发布任何壁纸、截图、公共 assets、个人配置或预编译 C++ 后端；保留 GPL-3.0-only 与上游归属。

## 安装与升级

从本 Release 下载四个附件，按 `INSTALL-v0.0.2.md` 校验并安装。
[在线插件安装说明](https://github.com/zcmmy/gnome-wallpaper/blob/v0.0.2/docs/PLUGIN-INSTALL.md)。

插件包包含 GNOME 层及辅助任务；动态播放仍需要独立 portghost 后端和用户自备资源。
本次 C++ 渲染器相对 v0.0.1 未修改，已有后端无需重新编译。
原子安装器保留旧插件目录与已有设置，不自动启用、重启或改变当前桌面。
磁盘安装成功不代表当前会话已更新；通常在下次登录加载新版，动态播放仍需用户显式开启。

## 验证与限制

- 发布前运行 `make check`，涵盖 C++ 回归、GNOME 管理与截图、合成引用、Forge 过滤、原子 schema 更新、图库操作和维护检查。
- 插件包检查版本、模块引用、schema、ZIP 完整性与发布边界；两次构建比较校验值，并在临时目录验证安装与升级。
- 此前已通过空工作区、工作区切换、最后一个应用关闭、全屏应用与热更新隔离测试。
- 用户已在真实桌面确认空工作区顶栏与 Dock 正常；headless 测试不能独立验证物理显示器直接输出路径。
- 验证平台为 Debian 13 / GNOME 48 / Wayland / x86_64；未验证全部 metadata 声明的版本。
- 场景特效兼容性取决于后端，运行包以 scene/video 为目标，不包含完整 Web 壁纸依赖。
