# GNOME Wallpaper v0.0.3

版本日期：2026-10-19。稳定源码分支：`main`；开发分支：`dev`。
本次合并并同步源码，不创建或更新 GitHub Release，不上传新的安装附件。
GitHub Release 保持 v0.0.2；v0.0.3 附注标签仅保存在本地，避免触发标签发布工作流。

## 多语言文字

- 修复部分壁纸显示系统音乐信息或场景文字时，中日韩等文字缺字、乱码的问题。
- 保留原字体；原字体缺少字形时，通过 Fontconfig 查找系统中覆盖对应字符的字体。
- 测宽、截断与绘制使用相同字体选择，正确处理字体集合索引、字形位图和无效 UTF-8。
- 新增 Fontconfig 开发与运行依赖；系统仍需安装覆盖目标语言的字体，不捆绑或承诺支持所有语言字体。

见 [多语言文字与验证](../UNICODE-TEXT.md)。本修复涉及 C++ 后端，单独升级 GNOME 插件不能修复旧后端的文字问题。

## 工作区焦点

动态壁纸窗口在切换工作区时可能获得焦点，旧逻辑随后尝试激活其他工作区的应用，
触发 GNOME 的“应用已就绪”提示。
现在只在壁纸确实获得焦点时，将输入焦点归还给当前工作区可见的应用；空工作区则释放焦点。
不激活其他工作区窗口、不恢复最小化窗口，也不关闭系统或其他应用的正常通知。

修复不改变顶栏、Dock、Forge 配置、播放 FPS、动态开关或渲染管线。
用户已在真实桌面确认工作区切换不再出现多余通知。
见 [工作区焦点的原因、测试与当前会话更新](../WORKSPACE-FOCUS.md)。

## 版本与升级

项目版本为 v0.0.3，插件 metadata 整数版本为 3，GNOME 代码修订号为 15。
更新时应使用相应源码构建后端，并通过原子安装器更新插件；不原地覆盖已映射的程序、共享库或 schema。
磁盘代码更新不等于当前会话重新加载；仍遵循显式启用动态的规则。
本机两项修复此前已经部署，工作区焦点的当前会话更新已获用户确认；本次版本合并不再重启或重载桌面。
