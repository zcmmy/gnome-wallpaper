# 场景壁纸渲染兼容性

这些修复针对渲染器对骨骼动画、特效链和场景脚本的兼容性，已纳入 v0.0.1。
测试素材仅用于发现和复现问题。本项目不提供具体壁纸的名称、Workshop ID、下载信息或素材。

## 适用场景

| 技术特征 | 原异常及修复 |
| --- | --- |
| 使用 Puppet 骨骼动画的壁纸 | 骨骼元数据解析错位；Y 坐标反射后背面剔除错误隐藏图像 |
| 同时使用 Puppet 网格与多层位移特效的壁纸 | 特效遮罩与变形后网格坐标错位，导致局部抽动或扭曲 |
| 使用旧音频条、边框或环形频谱特效的壁纸 | 部分旧着色器语法不兼容 GLSL，导致特效编译失败或异常覆盖层 |
| 使用分组脚本或跨图层文字更新的壁纸 | 属性脚本绑定、初始化次序和文字更新路径不完整 |
| 引用缺失用户图片的壁纸 | 不透明占位纹理形成白块，改用透明纹理 |

修复作用于渲染器，不改写用户的 project.json 或场景包。
第三方素材、解包内容、静态图及本机测试日志均不随代码发布。

## 渲染器改动

- 在着色器预处理阶段识别限定特征的旧特效模板：修正音频条多余的条件结束指令、方向变体对只读片元 UV 的写入、Frame Builder 的数值条件，以及旧环形频谱对 float 数组的二级索引和隐式向量截断。没有这些特征的源码保持原样。
- Puppet 的 MDLS 骨骼记录尾部按两个有界 NUL 字符串读取，兼容空字符串旧文件和带 JSON 元数据的新文件。
- 2D Puppet 的 Y 反射同时修正三角形绕序，保留材质背面剔除语义。
- 无绘制内容的分组也具有脚本属性；场景全部对象创建完成后再执行属性脚本初始化。
- 图层包装对象保持稳定身份；回调绑定自身图层；补全 getParent()、name、id 和非编辑器查询。属性写入同步到渲染数据，字符串使用明确的字符串重载。
- 文本由共享场景脚本引擎更新，删除文本对象的第二套独立脚本执行。其他图层写入以及初始空文字均可显示，只有内容或像素字号变化才重新栅格化。
- 缺失用户图片或 Windows 快捷方式图标使用透明纹理，避免白色占位块；不会执行 Windows 快捷方式。

## Puppet 与特效的绘制顺序

旧管线在第一遍材质绘制时就应用 Puppet 网格。对于网格局部位置与源图 UV 不重合、
且后续特效仍按源图坐标读取遮罩的壁纸，位移会被施加到错误的图像区域。
这会表现为局部来回抽动或变形，看起来像骨骼错位。
在诊断场景中，去除骨骼动画、只保留特效仍可复现；只保留骨骼则轮廓正常。

修复把网格绘制移到效果链的最后一遍。材质和前序特效先在完整原图 UV 空间处理，
最终通道才将结果映射到 Puppet 网格。单通道模型仍直接绘制网格，非 Puppet 图层不变。
不关闭作者特效、不修改壁纸包、不改变 FPS 或日常渲染分辨率，也不增加额外绘制通道。

## 验证方法

```bash
bash renderer/tests/check.sh
python3 renderer/tests/check-scene-scripts.py
python3 renderer/tests/check-puppet-effects.py
bash gnome/tests/check.sh
```

先按构建说明准备渲染器。骨骼测试默认使用自建二骨骼合成文件，不包含第三方素材。
脚本集成测试使用独立 headless GNOME、独立 DBus 和临时目录，验证后创建图层、父分组、
稳定身份、自定义属性、跨层赋值、正确回调图层和实际文字像素。
需要本机 GNOME、GJS、GdkPixbuf 与已准备的渲染器依赖。

Puppet 特效测试使用自建的偏移、缩小网格和分区遮罩验证实际像素，覆盖零、一、两层特效。
旧实现会在遮罩位置断言失败，修复版三种情况通过。
可传 --renderer /path/to/renderer 对照其他构建。

## 验证结果与边界

- C++ 构建、渲染器回归、脚本隔离场景及 GNOME 测试套件通过。
- 使用上述技术的部分壁纸通过普通渲染及 4K→1080p 截图验证，相关着色器编译异常已消除。
- 骨骼测试确认蒙皮顶点随时间变化；截图测试不播放系统音频、不移动真实鼠标，因此不作为所有音频和鼠标交互均已人工验收的证明。
- 同一动画时刻的对照帧仅保存在本机忽略的 reports/ 下。诊断时临时固定时间，相关诊断代码已在正式构建前移除；结果不代表与 Windows 原生 Wallpaper Engine 逐像素一致。
- 部分壁纸自身包含不存在的图层引用；渲染器不会猜测作者意图替换引用，这类脚本异常仍会记录。
- Windows 应用启动、缺失的用户自定义资源和未实现的专用脚本接口不属于这些兼容修复的覆盖范围。
