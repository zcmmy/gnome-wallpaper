# 完整包重构验证记录

2026-10-19，`feature/extension-package` 开发候选；不改变 v0.0.3 稳定版与已发布附件。
目标环境：Debian 13、GNOME 48、Wayland、x86_64。后端重新以 Release 配置构建，未改变渲染算法、播放分辨率或 FPS 行为。

## 已完成

- `make check`：渲染器回归、GNOME 生命周期/静态/轮换/截图、Forge/焦点/合成、许可证与维护检查。
- 资源事务：中文和空格路径、批量导入、重复跳过、保留用户静态图、assets 替换确认、取消、空间不足、损坏入口、符号链接拒绝、写锁、版本拒绝和提交中断恢复。
- 完整包：后端与 215 个私有共享库、14 个宿主 ABI/图形库边界；最小加载环境仅暴露私有库及声明的宿主库，后端正常加载。此数量仅记录当前构建，不是未来版本的固定值。
- GNOME ZIP 安装实测：执行权限保留，更新替换 inode，旧 mmap 内容保留；无自动回滚副本。正式入口采用附带安装器，增加宿主/完整性预检、任务退出等待和原子备份回滚。
- 完整包安装、再次更新、旧目录回滚：临时路径内验证通过，用户数据保留。另用独立的真实 GSettings 后端验证旧 runtime 升级和回滚，恢复旧后端入口并保留图库位置、FPS 与静态模式。
- 隔离图形会话：隐藏源码、构建和旧 runtime 目录，程序目录只读；管理界面、静态应用列表、场景/合成视频动态播放、独立静态截图及再次启停通过。
- Forge 与其他现有美化扩展共存：普通/空工作区切换、顶栏与 Dock 映射、可见/最小化窗口焦点、正常应用通知、真实全屏窗口、关闭最后一个应用及停用回收检查通过。
- 高质量截图期间，原动态进程与 FPS 未改变；静态模式无渲染器、鼠标桥或合成锁。真实桌面 GNOME 设置前后比较一致。

## 范围与发布门槛

上述图形测试使用本机独立 XDG、DBus 和 headless GNOME，不等同于全新虚拟机或真实物理桌面的人工验收。
本轮没有部署到用户当前会话，没有改变现有外观、登录启动项、播放设置，也没有合并或发布。

公开发布前仍需运行一次干净 Debian 13 容器构建与目标系统安装验收，下载并附带清单指定版本的全部依赖对应源码，再按发布流程核对产物。
已提供锁定输入的容器配方、源码收集器及手动工作流；本机未执行容器配方，不宣称该工作流已在远端通过。
当前开发候选带项目对应源码与许可证；依赖源包收集是公开 Release 的强制组包门槛。
不承诺其他发行版、架构、GNOME 版本、物理显示器直接输出路径或未测试视频编解码组合。
